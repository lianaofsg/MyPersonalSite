# MyPersonalSite
Built a personal website to showcase projects, technical skills, and professional experience with an interactive and responsive design. 


## 🚀 Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Compile TypeScript

```bash
npm run build
```

### 3. Start Development Server

```bash
npm start
```

The website will open at `http://localhost:3000`
